# 回路残响（Echo Circuit）

一款原创的洛克人式 2D 动作平台游戏原型。核心创意是**规则芯片**：打败守律者 Boss 后获得它掌管的规则，可以改写整个关卡的物理规则；两块芯片同时开启还会产生组合效果。

整个游戏是单个 HTML 文件，用浏览器直接打开 `index.html` 就能玩，没有外部依赖。图片以内嵌数据的形式包含在文件里，音乐和音效都在浏览器中实时合成。

## 操作

| 按键 | 作用 |
|---|---|
| ← → / A D | 移动 |
| Z / K / 空格 | 跳跃（按得越久跳得越高） |
| X / J | 射击（按住蓄力，松开发射） |
| C / L / Shift | 冲刺；冲刺中起跳 = 冲刺跳 |
| 贴墙按跳 | 蹬墙跳 |
| ↓ + 跳 | 穿过薄平台 |
| Q | 规则芯片「霜钟」：水 ⇄ 冰 |
| E | 规则芯片「磁暴」：吸附金属，倒挂行走 |
| 1 ~ 0 | 传送到各存档点（测试用） |
| Tab | 手感调参面板 |
| R / T | 回到存档点 / 从头开始 |
| M / N | 静音全部 / 只开关音乐 |

支持手柄（A 跳、X 射击、B/RB 冲刺、LB 霜钟、LT 磁暴）和手机触屏。

## 已实现内容

- **手感**：120Hz 固定步长物理 + 插值渲染；加速度与摩擦、惯性保留、上升下落不对称重力、顶点滞空、松键截断、土狼时间、跳跃缓冲、撞角修正；冲刺、冲刺跳、蹬墙跳、滑墙
- **打击感**：顿帧、震屏、挤压拉伸、残影、粒子、合成音效
- **Boss 1「霜钟守卫」**：跳砸冰刺波、钟鸣冻结水池、滑行冲撞、冰锥雨，二阶段加速与连招
- **Boss 2「磁暴裁缝」**：投针、磁力牵引、倒挂天花板追击后砸落
- **双芯片组合「磁冰」**：两块芯片同时开启时冰也带磁性，可以倒挂在冻结的悬空水体下行走
- **像素美术**：主角 13 帧动画、4 种敌人、2 个 Boss；按地图自动拼接的雪顶砖石、冰锥、金属图块，钟楼远景与水厂中景视差，飘雪
- **音乐**：关卡曲《冰封钟楼》（D 小调 118 BPM）与 Boss 曲《霜钟审判》（E 小调 148 BPM），根据战斗状态自动切换

## 目录

```
index.html          游戏本体（单文件）
art/scripts/        生成像素精灵与概念图的 Python 脚本（需要 Pillow）
art/sheets/         嵌入游戏的精灵图
art/boards/         概念图、设计稿与游戏内截图
```

重新生成美术：在 `art/scripts/` 目录下运行对应脚本，例如 `python3 hero3.py`。生成的精灵图需要再转成 base64 写回 `index.html`。
